# Book V2 Commentary Style Guide

## Purpose

This guide defines how optional DeepSeek commentary should sound in Book v2.

The goal is:

- make the chapter read like a compact research monograph
- avoid detached AI-sounding comments
- preserve deterministic factual control

## Tone

Commentary should sound like:

- a concise technical research note
- practical and evidence-aware
- calm, direct, and non-promotional
- close in spirit to a chart-pattern reference manual

It should not sound like:

- a chatbot explanation
- a motivational article
- a market newsletter
- a trading callout post

## Writing Form

The preferred form is:

### 1. Short observation-first opening

Start by stating the main takeaway from the deterministic chapter.

Example shape:

- the pattern is common but weak
- the pattern is sparse but promising
- the Vietnam sample is stronger than the reference baseline
- the pattern remains unstable despite structural cleanup

### 2. Benchmark-aware interpretation

Tie the commentary back to the Bulkowski baseline.

Do:

- explain whether Vietnam is stronger, weaker, or simply sparse
- discuss likely reasons only when those reasons are consistent with the deterministic facts

Do not:

- invent causal stories unsupported by the chapter

### 3. Practical caution

Every commentary block should include some caution language when appropriate:

- sample is thin
- false positives remain a risk
- watchlist status is not promotion
- research-only status means no strategy endorsement

### 4. Application note

End with a practical but disciplined note:

- what this chapter is useful for
- what it is not yet strong enough for

## Required Section Layout

Commentary should use these four Markdown headings:

- `### Nhận xét chính`
- `### So với mốc tham chiếu`
- `### Lưu ý về chất lượng mẫu`
- `### Hàm ý sử dụng`

## Fact Guardrails

The commentary must obey all of these rules:

- no invented facts
- no invented numbers
- no new rankings
- no status changes
- no contradiction of the deterministic chapter
- no trading recommendation stronger than the chapter's governance status

If the deterministic chapter says:

- `candidate`, commentary may discuss evaluation potential
- `watchlist`, commentary may discuss promise with caution
- `research_only`, commentary must stay in research framing
- `retired`, commentary must not rehabilitate the pattern

## Style Guardrails

Do:

- prefer short paragraphs
- make claims close to the evidence
- write in a compact reference-like style
- compare current Vietnam evidence against the reference baseline

Do not:

- over-explain obvious table values
- repeat every metric from the chapter
- imitate copyrighted wording verbatim
- write vague generic filler

## Sparse-Data Behavior

When the chapter is sparse or lacks benchmark support:

- say so directly
- avoid pretending the evidence is stronger than it is
- shift the discussion toward monitoring or future research

## Final Rule

The commentary is editorial only.

If the commentary is removed, the chapter must still be complete and correct.
